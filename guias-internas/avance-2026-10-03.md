### Punto importante de infraestructura

Hubo un problema de entorno local: el servidor HTTP estaba sirviendo una carpeta equivocada del proyecto, por lo que la página aparecía antigua y el slider parecía que no funcionaba.

La solución correcta fue servir la carpeta real:

```bash
cd "C:\Users\josue\Desktop\sitios cloudflare\sanitarios-la-pampa\public"
python -m http.server 8001
```

Luego se usa esta URL para revisar la galería:

```text
http://localhost:8001/galeria.html
```

Si el navegador muestra una versión anterior, conviene recargar con Ctrl + F5 o abrir la URL en modo incógnito para evitar caché.

## Recomendación para futuras modificaciones

- Antes de tocar imágenes o scripts del slider, revisar que el servidor local esté apuntando a la carpeta `public/` correcta.
- Si se cambian las imágenes del slider, conviene mantener nombres distintos o actualizar el `src` en el HTML para evitar confusión con caché.
- No hacer push ni deploy sin permiso del usuario.
- Para futuras revisiones, usar esta guía y la carpeta local `guias-internas/` como referencia del estado del proyecto; no colocar documentación privada dentro de `public/`.
