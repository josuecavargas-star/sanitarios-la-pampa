## Cambios realizados

### Migración de Netlify a Cloudflare Workers

El sitio vivía en `C:\Users\josue\Desktop\netlify\sanitarios-la-pampa` como sitio estático de Netlify.
Se copió el proyecto a la carpeta padre de sitios de Cloudflare y se rearmó con la misma estructura
que usa **Salmo 27 Librería**.

Pasos realizados:

1. Se creó la carpeta `public/` y se movieron dentro los archivos del sitio con `git mv`
   (se conserva el historial de Git):
   - `index.html` → `public/index.html`
   - `css/` → `public/css/`
   - `js/` → `public/js/`
   - `img/` → `public/img/`
   - `guia/` → `public/guia/`
2. Se creó `wrangler.jsonc` en la raíz del repo:

```json
{
  "name": "sanitarios-la-pampa",
  "compatibility_date": "2026-09-01",
  "assets": {
    "directory": "./public"
  }
}
```

3. `CONVENCION_COMMITS.md` quedó en la raíz (no se publica en la web).
4. Se creó `AGENTS.md` con las instrucciones de deploy para agentes de IA.

No hizo falta modificar `index.html`: todas las rutas (`css/styles.css`, `js/main.js`, `img/...`)
son relativas, así que siguen funcionando dentro de `public/`.

## Pasos pendientes en Cloudflare

1. Crear el proyecto en el dashboard de Cloudflare con el nombre `sanitarios-la-pampa`
   (debe coincidir con el `name` de `wrangler.jsonc`).
2. Conectar el repositorio `josuecavargas-star/sanitarios-la-pampa`, rama `main`.
3. Build command vacío, deploy command `npx wrangler deploy`, root directory `/`.
4. URL esperada: `https://sanitarios-la-pampa.josuecavargas.workers.dev`
